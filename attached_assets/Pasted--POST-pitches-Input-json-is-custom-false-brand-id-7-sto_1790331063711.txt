## `POST /pitches/manual`

**Input**
```json
{
  "brand_id": 7,
  "status": "sent",
  "sent_at": "2026-09-25"
}
```

Or for a custom brand:

```json
{
  "custom_brand_name": "Example Brand",
  "status": "sent",
  "sent_at": "2026-09-25"
}
```

**Sample response**
```json
{
  "id": 43,
  "brand_id": 7,
  "brand_name": "Studio Fit",
  "is_custom": false,
  "story": "",
  "product_reference": null,
  "past_brand_partnership": null,
  "content_link": null,
  "contact_name": null,
  "contact_email": null,
  "pitch_text": null,
  "status": "sent",
  "source": "manual",
  "sent_at": "2026-09-25",
  "agreed_rate": null,
  "created_at": "2026-09-25 12:05:00+00"
}
```

## `POST /matches/me/refresh`

**Input**

Query parameter:

```text
/matches/me/refresh?limit=20
```

**Sample response**

Same response shape as `GET /matches/me`, including `matches`, `total`, `cached`, and `computed_at`.
