Build a completely new multi-step creator onboarding flow for the MAVLIT web application.

## Goal

Create a modern, professional onboarding experience for first-time creators joining MAVLIT.

The onboarding should feel similar to SaaS products like Notion, Stripe, and HubSpot.

Use a clean card-based UI with:

* Progress indicator at the top
* Previous / Continue buttons
* Auto-save form state
* Smooth slide animations between steps
* Mobile responsive design
* Form validation
* Dark mode support if already available in the app

---

# Step 1: Welcome Screen

Title:

Welcome to MAVLIT

Subtitle:

MAVLIT helps creators discover brands that are actively working with creators in their niche.

We analyze:

* Your content
* Your niche
* Brand partnerships
* Audience fit

to find sponsorship opportunities that match your profile.

Show:

* MAVLIT logo
* Short explanation
* "Get Started" button

Clicking Get Started moves to Step 2.

# Step 2: Creator Information

Collect:

### Full Name

Text input

### City

Text input

### Country

Text input

### Age

Number input

### Gender

Dropdown

Options:

* Male
* Female
* Non-binary
* Prefer not to say
* Other

### Content Description

Textarea

Placeholder:

Describe the type of content you create and the audience you serve.

### Primary Platforms

Multi-select dropdown.

Options:

* Instagram
* YouTube

Validation:
At least one platform must be selected.

Continue button.

Routing rules:

If only Instagram selected:
→ Open Instagram Profile Step

If only YouTube selected:
→ Open YouTube Profile Step

If both selected:
→ Open Instagram Profile Step first
→ Then YouTube Profile Step

# Submission Behavior

When user clicks Submit Profile:

1. Validate all required fields
2. Save onboarding data
3. Mark user onboarding_complete = true
4. Redirect to Creator Dashboard
5. Show success toast

Profile created successfully.
